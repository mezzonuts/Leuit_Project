## 🎯 Detailed Task Breakdown

### Day 29: Multi-tenant Architecture

**Backend Tasks:**
- [ ] `Tenant` model: id, name, slug, subdomain, settings (JSON), plan, status, created_at
- [ ] Row-level security: PostgreSQL RLS policies per tenant
- [ ] Tenant middleware: extract tenant from subdomain/header/JWT
- [ ] Tenant context in all queries (auto-filter by tenant_id)
- [ ] Tenant CRUD API: `/api/v1/tenants` (admin only)

**Frontend Tasks:**
- [ ] Tenant switcher (if multi-tenant user)
- [ ] Tenant-aware API client (auto-inject tenant_id)

**Tests:** 15 backend + 5 frontend

---

### Day 30: White-label System

**Backend Tasks:**
- [ ] `Branding` model: tenant_id, logo_url, primary_color, secondary_color, font_family, favicon_url, custom_css
- [ ] Theme API: GET/PUT `/api/v1/branding`
- [ ] Custom domain: CNAME verification, SSL (Let's Encrypt), DNS challenge
- [ ] Email templates: per-tenant Handlebars templates, SendGrid/Mailgun integration

**Frontend Tasks:**
- [ ] Theme provider: CSS variables from branding API
- [ ] Dynamic favicon/logo injection
- [ ] Custom CSS injection (sanitized)

**Tests:** 10 backend + 10 frontend

---

### Day 31: Advanced Analytics v2

**Backend Tasks:**
- [ ] Cohort analysis: retention curves, LTV prediction
- [ ] Funnel analysis: multi-step conversion, drop-off points
- [ ] Predictive alerts: anomaly detection (Isolation Forest), threshold alerts
- [ ] Analytics API: `/api/v1/analytics/cohort`, `/funnel`, `/anomalies`

**Frontend Tasks:**
- [ ] Cohort heatmap (Recharts)
- [ ] Funnel visualization
- [ ] Alert dashboard with severity badges

**Tests:** 15 backend + 10 frontend

---

### Day 32: Billing & Subscription

**Backend Tasks:**
- [ ] `Subscription` model: tenant_id, plan_id, status, current_period_start/end, cancel_at_period_end
- [ ] `Plan` model: name, price_id (Stripe/Midtrans), features (JSON), limits (JSON)
- [ ] Stripe webhook: `checkout.session.completed`, `invoice.payment_failed`, `customer.subscription.deleted`
- [ ] Midtrans webhook: `settlement`, `deny`, `cancel`, `expire`
- [ ] Proration logic: upgrade/downgrade mid-cycle
- [ ] Invoice generation (PDF), email delivery

**Frontend Tasks:**
- [ ] Billing page: current plan, usage, upgrade/downgrade modal
- [ ] Invoice history with PDF download
- [ ] Payment method management (Stripe Elements / Midtrans Snap)

**Tests:** 15 backend + 10 frontend

---

### Day 33: Advanced Reporting

**Backend Tasks:**
- [ ] Report scheduler: cron expression, template (HTML/PDF/Excel), recipients, format
- [ ] Report templates: Jinja2/Handlebars, data injection, charts (base64 PNG)
- [ ] Export formats: PDF (WeasyPrint), Excel (openpyxl), CSV
- [ ] Email delivery: SendGrid, template rendering, attachments
- [ ] Scheduler: APScheduler/Celery Beat, timezone support

**Frontend Tasks:**
- [ ] Report builder: drag-drop sections, filters, scheduling UI
- [ ] Report history: status, download, resend

**Tests:** 10 backend + 10 frontend

- [ ] Metro config: path aliases, SVG transformer, Hermes
- [ ] EAS Build config: profiles (development, preview, production)

**Tests:** 5 mobile

---

### Day 37: Offline-First Architecture

**Mobile Tasks:**
- [ ] Redux Persist + MMKV (fast, encrypted storage)
- [ ] Sync engine: outbox pattern, operation queue, exponential backoff
- [ ] Conflict resolution: last-write-wins / server-wins / custom merge
- [ ] Background sync: expo-task-manager / react-native-background-fetch
- [ ] Network status: NetInfo, automatic retry on reconnect
- [ ] Migration system: schema versioning, migration scripts

**Backend Tasks:**
- [ ] Sync endpoint: `/api/v1/sync` (batch operations, vector clocks)
- [ ] Conflict resolution endpoint
- [ ] Delta sync: `since` timestamp, incremental payloads

**Tests:** 10 mobile + 5 backend
