# Day 23 Plan: Accessibility (a11y)

**Focus:** WCAG 2.1 AA compliance across LEUIT desktop app
**Predecessor:** Day 22 Performance Tuning (PR #23)

---

## Goals

1. Keyboard navigation fully usable on all pages
2. Screen-reader semantics on core flows
3. Color contrast and focus visibility fixes
4. Accessible forms, modals, and tables
5. Test coverage for a11y utilities

---

## Tasks

### 1. Audit & Tooling
- Install `axe-core` (dev) or run manual axe checks on key pages
- Add Playwright a11y smoke test (if Playwright suite active) or document manual checklist
- Scan: Dashboard, Inventory, BOM, Purchases, Sync, modals

### 2. Keyboard Navigation
- Verify Tab/Shift+Tab order in Layout sidebar → header → content
- Skip-to-content link in `Layout.tsx`
- Focus trap in `DatabaseUnlockModal`, `IngredientDrawer`, `PurchaseEntryDrawer`, `PosSyncDrawer`, `StockOpnameModal`
- Escape closes drawers/modals
- Focus restore to trigger element on modal close

### 3. ARIA & Semantics
- Modal components: `role="dialog"`, `aria-modal="true"`, `aria-labelledby`, focus management
- Tables: `<caption>` or `aria-label`, `scope="col"` on headers
- Charts (`UsageTrendBarChart`): `aria-label` / visually-hidden data summary
- Live regions for toasts/sync results
- Icon-only buttons: `aria-label` (Sidebar toggle, scanner, actions)

### 4. Forms
- Every input has `<label>` (visible or `aria-label`)
- Error messages: `aria-describedby`, `role="alert"` / `aria-invalid`
- Stock opname & purchase entry forms: announce validation errors

### 5. Color & Contrast
- Text/background pairs ≥ 4.5:1 (normal), ≥ 3:1 (large)
- Severity colors (alerts: high/medium) paired with icon + text, not color alone
- Focus indicators visible on all interactive elements (2px outline min)

### 6. Motion & Media
- Respect `prefers-reduced-motion` for spinners/animations
- Loader2 spinner fallback: `role="status"` + `aria-label` in lazyLoad Suspense

### 7. Tests
- Frontend: unit tests for new a11y utilities (focus trap hook, skip link)
- Target: ≥ 6 new a11y tests
- Regression: `pnpm typecheck` 0 errors, `pnpm test` pass, `uv run pytest` pass
- Lint clean
