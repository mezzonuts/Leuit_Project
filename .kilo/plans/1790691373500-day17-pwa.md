# Day 17 — Mobile Companion (PWA)

**Proyek:** LEUIT
**Status:** 📋 Planned
**Depends on:** Day 16 ✅ (Multi-outlet Support, PR #17)

---

## Goal

Mengubah LEUIT menjadi instalable Progressive Web App dengan dukungan offline: manifest + service worker + offline queue, install prompt, dan starter kit React Native di `mobile/` sebagai jalur mobile companion.

---

## Scope

### 1. PWA Manifest (Frontend)
- [ ] `frontend/public/manifest.json`: `name`, `short_name`, `start_url`, `display: standalone`, `theme_color`, `background_color`
- [ ] Ikon 192/512 PNG + maskable icon; splash screen meta tags
- [ ] Daftarkan manifest di `index.html`
- [ ] Verify: DevTools → Application → Manifest valid, Lighthouse PWA audit

### 2. Service Worker (Frontend)
- [ ] Service worker via Workbox (atau vanilla SW bila build Vite sudah cukup sederhana)
- [ ] Strategy: cache-first untuk asset statis (JS/CSS/fonts/icons); network-first (fallback cache) untuk API
- [ ] Register SW di production build saja (guard `import.meta.env.PROD`) — jangan mengganggu dev server
- [ ] Versioned cache + cleanup cache lama saat activate
- [ ] Offline fallback page / stale indicator di UI bila API gagal

### 3. Offline Queue (Frontend)
- [ ] IndexedDB queue untuk mutation (purchase entry, stock opname, POS sync payload) yang terjadi saat offline
- [ ] `useOfflineSync` hook: enqueue saat `navigator.onLine === false`, flush saat reconnect
- [ ] Deduplikasi / idempotency key per mutasi agar replay aman
- [ ] UI: badge/indikator "X perubahan menunggu sync"
- [ ] Conflict handling minimal: server timestamp menang, payload lokal disimpan untuk audit

### 4. Install Prompt (Frontend)
- [ ] Tangkap `BeforeInstallPromptEvent`, tahan event, render tombol install custom ("Install LEUIT")
- [ ] Hide tombol bila sudah terpasang (`display-mode: standalone` / `getInstalledRelatedApps`)
- [ ] Handle `userChoice` (accepted/dismissed) untuk analytics sederhana / persist flag

### 5. React Native Starter (`mobile/`)
- [ ] Folder `mobile/` di root repo (monorepo), `expo init` minimal, belum perlu full feature parity
- [ ] Shared types: re-export / duplikasi ringan type dari `frontend/src/types` yang relevan (outlet, ingredient, auth)
- [ ] README singkat: cara run (`npx expo start`), scope starter, rencana integrasi API LEUIT (base URL, license header)
- [ ] YAGNI: belum perlu push notification, belum perlu native modules di luar Expo defaults

### 6. Tests & Quality
- [ ] Frontend test target: 15 test — manifest shape, SW registration guard, offline queue enqueue/flush, install button states, useOfflineSync hook
- [ ] `pnpm typecheck` + `pnpm test` hijau; `pnpm build` sukses (SW ter-generate di dist)
- [ ] CI hijau sebelum merge
- [ ] Catatan: SW/E2E yang bergantung browser penuh boleh di-skip di CI unit test (mock `navigator.serviceWorker`)

---

## Acceptance Criteria

1. App bisa di-install dari Chrome/Edge (desktop) & mobile browser; tampil standalone tanpa chrome browser.
2. Asset statis tetap tampil saat offline; API memakai network-first dengan fallback cache.
3. Mutasi saat offline masuk IndexedDB queue dan ter-flush otomatis saat kembali online.
4. Tombol install custom tampil hanya bila install belum tersedia; tidak muncul di mode standalone.
5. `mobile/` starter jalan via `npx expo start` dan memiliki shared types minimal.
6. Semua test baru + existing hijau; lint/typecheck bersih; CI hijau.

---

## Architecture Notes

- **Local-first tetap utama:** PWA hanya lapisan presentasi + resilience; database tetap SQLCipher di desktop, queue IndexedDB di browser.
- **Service worker scope:** hindari SW intercept request ke API yang butuh auth fresh — network-first + skip cache untuk endpoint ber-guard license.
- **Build pipeline:** pastikan `pnpm build` output tetap dipakai PyInstaller bundling (Day 13) — SW file ditambahkan ke dist, tidak mengubah entrypoint binary.
- **React Native:** starter terpisah di `mobile/`, share type via package workspace bila pnpm workspace sudah ada; jangan monorepo-refactor besar-besaran (YAGNI).
- **Performance:** cache hanya asset dengan hash filename agar aman terhadap update.
