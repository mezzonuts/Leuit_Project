## 4. Deduplication Logic Verified

```python
raw_hash = f"{order_id}_{timestamp}_{menu_identifier}"
tx_hash = hashlib.sha256(raw_hash.encode()).hexdigest()
```

**Tests confirm:**
- Same input → same hash (deterministic)
- Different input → different hash (collision avoidance)
- Hash length = 64 hex chars
- All chars in `0-9a-f`
