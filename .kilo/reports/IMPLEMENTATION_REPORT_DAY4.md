## 2. Schema Hardening

### Before
```python
class IngredientBase(BaseModel):
    barcode_sku: str | None = Field(None, max_length=100)
    cost_per_unit: float = Field(..., ge=0)
```

### After
```python
class IngredientBase(BaseModel):
    barcode_sku: str | None = Field(None, max_length=100, pattern=r"^[A-Za-z0-9\-_]+$")
    cost_per_unit: float = Field(..., gt=0)
```

| Field | Before | After | Alasan |
|---|---|---|---|
| `barcode_sku` | max_length=100 only | + regex `^[A-Za-z0-9\-_]+$` | Alphanumeric + dash/underscore only |
| `cost_per_unit` (create) | `ge=0` | `gt=0` | HPP tidak boleh 0 |
| `cost_per_unit` (update) | `ge=0` | `ge=0` | Allow 0 for temp adjustment |

## 3. Route Ordering Fixed

**Problem**: Parameterized route `/{ingredient_id}` shadows static routes like `/valuation/summary`.

**Solution**: Move static routes BEFORE parameterized routes in `inventory.py`:
```python
# Static routes first
@router.get("/valuation/summary", ...)
@router.get("/valuation/items", ...)
@router.get("/valuation/export-csv", ...)
@router.get("/usage-trend", ...)
@router.get("/alerts", ...)

# Then parameterized
@router.get("/{ingredient_id}", ...)
@router.put("/{ingredient_id}", ...)
@router.delete("/{ingredient_id}", ...)
@router.post("/{ingredient_id}/stock-opname", ...)
```
